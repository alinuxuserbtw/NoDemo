# NoDemo

Hi :) NoDemo is a project made by myself. It removes the Minecraft demo mode limitations.

## Requirements

- Fabric Loader
- Fabric API
- Minecraft 26.3
- Java 25 or higher

## Things it can't do

- **Custom username:** It is recommended to install an in-game offline account manager, or (in some cases) use your launcher.
- **Playing on non-cracked servers:** This is a real limitation, sorry :(

## Building

    ./gradlew build

The jar will be in `build/libs/`. If you don't want to compile it, download the ready-made `.jar` from the Releases page.
