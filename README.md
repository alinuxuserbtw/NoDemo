# NoDemo

Hi :) NoDemo is a project made by myself. It removes the Minecraft demo mode limitations.

## Download (stable)

**Minecraft 26.3:** [NoDemo V1.0.1](https://github.com/alinuxuserbtw/NoDemo/releases/tag/v1.0.1)

## Requirements

- Fabric Loader
- Fabric API
- Minecraft 26.3
- Java 25 or higher

## Other versions (beta)

They may not be stable, but they are probably OK.

| Minecraft | Download |
|---|---|
| 1.16.5, 1.20.1, 26.2, 26.4 Snapshot 6 | [Compiled jars](https://github.com/alinuxuserbtw/NoDemo/releases/tag/beta_jar-v1.0.0) |
| 1.16.5, 1.20.1, 26.2, 26.4 Snapshot 6 | [Source code to compile](https://github.com/alinuxuserbtw/NoDemo/releases/tag/beta-v1.0.0) |

## Things it can't do

- **Custom username:** install an in-game offline account manager, or (in some cases) use your launcher.
- **Playing on non-cracked servers:** this is a real limitation, sorry :(

## Building

    ./gradlew build

The jar will be in `build/libs/`. If you don't want to compile it, download the ready-made `.jar` from the [Releases](https://github.com/alinuxuserbtw/NoDemo/releases) page.
